Comprendre la situation en quelques secondes et exécuter les actions fréquentes en très peu d'étapes.

Paramètres

TOP ACTION
+ Nouveau prospect

RECHERCHE
Ctrl/Cmd+K : recherche globale + navigation rapide + actions fréquentes.

DASHBOARD AUJOURD'HUI
- salutation/date ;
- KPI courts ;
- agenda ;
- appels à faire ;
- relances ;
- tâches ;
- alertes/deadlines ;
- activité récente ;
- aperçu pipeline ;
- activité GitHub optionnelle.

FICHE COMPANY
Header : nom, secteur, ville, lifecycle, score, dernière interaction, prochaine action.
Tabs : Aperçu / Contacts / Activité / Opportunités / Projets / Documents / Finance.
Action rapide persistante : Ajouter interaction.

SAISIE D'UN APPEL
Doit être extrêmement rapide :
1. résultat ;
2. note courte ;
3. objection facultative ;
4. prochaine action/date ;
5. enregistrer.
Objectif : quelques secondes après l'appel.

PIPELINE
Kanban desktop.
Vue liste alternative.
Drag & drop avec confirmation métier si passage en WON/LOST.
Sur mobile, privilégier liste/stages plutôt qu'un Kanban horizontal pénible.

CALENDRIER
Mois/semaine/jour.
Filtres par type.
Chaque événement ouvre l'objet lié.
Création rapide d'un événement ou d'une tâche.

PROJETS
Résumé en haut : statut, deadline, progression, client, valeur.
Sections : tâches, milestones, activité, GitHub, documents, finances.

RESPONSIVE
Desktop prioritaire pour administration.
Mobile pleinement utilisable pour :
- consulter Aujourd'hui ;
- appeler un prospect ;
- saisir le résultat ;
- consulter client ;
- tâches/calendrier.
Pas besoin de reproduire toutes les vues desktop à l'identique.

ÉTATS UX OBLIGATOIRES
- loading ;
- vide avec action utile ;
- erreur ;
- succès ;
- données périmées/synchronisation si intégration externe.

ACCESSIBILITÉ
- navigation clavier ;
- focus visible ;
- contraste suffisant ;
- couleur jamais utilisée comme seul indicateur ;
- labels explicites ;
- reduced-motion respecté.

MICROCOPY
Ton court, professionnel, opérationnel.
Exemples :
« 3 relances en retard »
« Aucun appel prévu aujourd'hui »
« Client gagné »
« Synchronisé il y a 4 min »
